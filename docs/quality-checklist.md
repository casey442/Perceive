# Pre-ship quality checklist

Run on every page before calling work done. All items blocking.

## Copy
- [ ] Headline 2–4 words, imperative, zero adjectives
- [ ] No superlatives; every proof point is a number with a short label
- [ ] Hero language sources from Tier A/B of the buyer-language database only
- [ ] Buyer vocabulary (packet, consent agenda, minute book, properly noticed); no "governance solution"
- [ ] One CTA verb ("See a demo"), identical in nav, hero, and final section
- [ ] Board members never framed as unprepared
- [ ] No world-changing language
- [ ] Product mechanics ≤1 light mention per homepage section; product tour lives on interior pages
- [ ] Stop-slop pass: zero em dashes, no filler adverbs, no actor-less passives, no "no X, no Y" listings, no "not X but Y", no rhetorical triplets
- [ ] Every AI mention shows page-level citation behavior
- [ ] No "more secure" claims; disclosure commitment only; no breach district counts
- [ ] No fabricated testimonials, logos, or customer counts
- [ ] Every statutory number verified against a live URL (Texas → AG handbook, not the statutes portal)

## Design
- [ ] Achromatic palette only: black / silver / white, R=G=B hexes; no blue, no pink
- [ ] Fraunces display + Newsreader text; Newsreader ≥13px
- [ ] Light background, dark text on all reading surfaces
- [ ] Labels/muted text ≥4.5:1 contrast (#757575 or darker on white)
- [ ] Homepage ≤2 scrolls below hero; sections full-bleed
- [ ] Motion only on skimmable content, pause control present, prefers-reduced-motion respected, 3–8 animated elements total
- [ ] One wink, at the exit; footer polished to hero standard
- [ ] Hero visual is the buyer's world (photography/film) or dense real content; no empty screenshots
- [ ] Mobile: single column, ≥44px touch targets, ≥16px body text
- [ ] Page <2MB, hero renders without JS
